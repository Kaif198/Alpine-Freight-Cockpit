# Authentic brand artwork

These are original assets from the organisations' official websites, included after the user's explicit request for real branding in the white redesign. Source URLs and capture hashes are in `docs/brand-assets.json` at the repository root. SVG paths and colours are not redrawn or altered. DSV is the exact inline SVG from its official homepage.

Trademarks remain the property of their owners. This independent portfolio is not affiliated with or endorsed by Red Bull or the data publishers. Real carrier logos identify source publications only; fictional tender partners retain their own names and are never presented as actual carrier performance.
